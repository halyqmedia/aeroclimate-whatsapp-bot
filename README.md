# Aeroclimate WhatsApp AI Agent (TypeScript, production-ready)

WhatsApp-бот, вентиляция/кондиционирование компаниясы Aeroclimate үшін. Claude API арқылы
клиенттермен сөйлеседі, лидтерді жинайды. Архитектура API шығынын азайтуға бағытталған:
Router → Cache → Claude тізбегі, қысқартылған контекст, токен/баға логы.

## Мүмкіндіктер

- **Message Router** — қарапайым сұрақтарды (баға, жұмыс уақыты, телефон, төлем, рахмет)
  Claude-сыз, `src/prompt/faq.json`-дан дайын жауаппен өңдейді
- **Conversation Memory** — тек соңғы 6 хабарлама + автоматты қысқаша қорытынды Claude-қа жіберіледі
- **Cache** — диалогтың бірінші сұрағы қайталанса, Claude қайта шақырылмайды (TTL 24 сағат)
- **Rate limit** — 1 пайдаланушы 30 секундта 10-нан көп сұрау жіберсе, күте тұруды сұрайды
- **Token/Cost logging** — әр Claude сұранысынан кейін input/output токен және $ баға логталады (`logs/requests.log`)
- **Provider interface** — Gemini қазір қосулы (Claude/OpenAI да интерфейс арқылы қолжетімді)
- WhatsApp қосылымы (QR), дауыстық хабарламаны Whisper арқылы тану, буки (тапсырыс) сақтау — бұрынғы MVP-дегідей сақталды

## Неге "Сәлем" Router-де жоқ

Бірінші хабарламада бот міндетті түрде атыңызды сұрап, мәзірді ұсынуы керек (`config/business.ts`
ішіндегі сценарий). Егер "Сәлем" Router арқылы дайын жауаппен өтіп кетсе — осы сценарий бұзылады.
Сондықтан сәлемдесу әрқашан Claude арқылы өтеді.

## Толтырылмаған FAQ санаттары

`src/prompt/faq.json`-да **мекенжай, Instagram, жеткізу** санаттары жоқ — бұл ақпарат әлі
берілмеген, ойдан шығармадым. Дерек болса, файлға өзіңіз қосыңыз немесе маған беріңіз.

## Кэштің шектеуі

Кэш тек **диалогтың бірінші сұрағы** үшін жұмыс істейді (`recent.length === 0`). Диалог
ортасында келген қайталама мәтінді әдейі кэштемедім — себебі сол сәттегі жауап сценарий
қадамына байланысты өзгереді (мысалы, әр клиент "иә" деп жазуы мүмкін, бірақ контексі бөлек).

## Орнату

```bash
npm install
cp .env.example .env   # GEMINI_API_KEY, OPENAI_API_KEY (Whisper үшін) толтырыңыз
npm run build
npm start
```

Даму кезінде қайта құрастырмай іске қосу үшін:

```bash
npm run dev
```

## .env параметрлері

| Айнымалы | Сипаттама | Әдепкі |
|---|---|---|
| `GEMINI_API_KEY` | Gemini API кілті (AI_PROVIDER=gemini кезінде міндетті) | — |
| `ANTHROPIC_API_KEY` | Claude API кілті (AI_PROVIDER=claude кезінде міндетті) | — |
| `OPENAI_API_KEY` | Whisper (дауыстық хабарлама) үшін әрқашан керек | — |
| `AI_PROVIDER` | `gemini` \| `claude` \| `openai` | `gemini` |
| `MODEL` | Таңдалған провайдердің моделі | `gemini-2.5-flash` |
| `MAX_TOKENS` | Жауаптың максимал ұзындығы | `500` |
| `TEMPERATURE` | Модель температурасы | `1` |
| `CACHE_TTL` | Кэш өмірі, секунд | `86400` (24 сағ) |

## Папка құрылымы

```
src/
  api/         AI провайдер интерфейсі мен іске асырулары (Claude/OpenAI/Gemini)
  services/    WhatsApp клиенті, хабарлама орchestrациясы, тапсырыс, транскрипция, rate limit
  router/      Claude-сыз жауап беретін Message Router
  cache/       Жауаптарды кэштеу (in-memory, Redis-ке ауыстыруға дайын интерфейс)
  memory/      Диалог тарихы + автоматты қысқаша қорытынды
  prompt/      Системный промпт құрастыру + faq.json
  config/      business.ts (бизнес деректері), env.ts (.env валидациясы)
  utils/       logger, token/cost есептеуіш
logs/          requests.log — әр сұраныстың логы (JSON lines)
```

## Провайдерді ауыстыру

Қазір `AI_PROVIDER=gemini` (`src/api/geminiProvider.ts`, `@google/genai` SDK). Claude-ге
қайту үшін `.env`-де `AI_PROVIDER=claude` қойыңыз — `ClaudeProvider` дайын тұр. OpenAI үшін
`AI_PROVIDER=openai` қойып, `src/api/openaiProvider.ts` ішінде `generateReply`-ды толтыру
керек (әзірге заглушка). Қалған код өзгермейді, себебі бәрі `AiProvider` интерфейсі арқылы
жұмыс істейді.

## Қайда буки (тапсырыс) сақталады

`bookings.json` — әр растатылған жазба осында қосылады (chatId, қысқаша мазмұн, уақыт).

## Белгілі шектеулер

- Диалог тарихы жадта (RAM) сақталады — бот қайта іске қосылса, ағымдағы диалогтар жоғалады
  (буки бөлек `bookings.json`-да сақталғандықтан бұл маңызды емес)
- Кэш пен rate limiter жад ішінде — бірнеше сервер данасында (horizontal scaling) бөлек
  Redis-ке көшу керек болады (`CacheProvider` интерфейсі осыған дайын)
- whatsapp-web.js — бейресми кітапхана, WhatsApp жаңарған сайын кейбір функциялар (мысалы,
  дауыстық хабарлама жүктеу) уақытша бұзылуы мүмкін
